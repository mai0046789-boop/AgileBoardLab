# AgileBoardLab
Lab 2 - Agile Project Board, User Stories and Team Workflow

## Project Overview
This project demonstrates how to use an Agile project board to manage a Library Book Search system[cite: 11].

## Project Scenario
The Library Book Search system allows students to search for books by title, author, and subject[cite: 11].

## Team Roles and Responsibilities
- **Project Owner:** Manages the repository, project board, and overall task organization[cite: 11].
- **Team Members:** Work on assigned user stories and technical tasks[cite: 11].
- **Reviewer:** Reviews completed tasks and checks whether acceptance criteria are satisfied[cite: 11].
- **Tester:** Checks functionality and records test results[cite: 11].

## User Stories
1. Search books by title[cite: 12].
2. Search books by author[cite: 12].
3. Search books by subject[cite: 12].
4. View book details[cite: 12].
5. Handle books not found[cite: 12].

Each user story includes acceptance criteria and related technical tasks on the project board[cite: 12].

## Project Workflow
Tasks move through the following stages:
1. **Backlog:** Tasks that have not been started[cite: 10, 12].
2. **Ready:** Tasks prepared for work[cite: 10, 12].
3. **In Progress:** Tasks currently being worked on[cite: 10, 12].
4. **Review:** Tasks being checked by a reviewer[cite: 10, 12].
5. **Done:** Tasks that have been completed and reviewed[cite: 10, 12].

## Definition of Done
A task is considered Done when:
- All acceptance criteria are satisfied[cite: 10, 12].
- The work has been tested[cite: 10, 12].
- Test results have been checked and recorded[cite: 10, 12].
- The work has been reviewed[cite: 10, 12].
- Any identified issues have been resolved[cite: 10, 12].
